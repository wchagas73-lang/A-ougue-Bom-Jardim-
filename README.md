# Açougue Bom Jardim — Cardápio Online

Projeto inicial de cardápio digital responsivo, preparado para evoluir para pedidos, painel administrativo e gestão por estabelecimento.

## Tecnologias
- React
- Vite
- CSS responsivo
- Lucide React

## Executar localmente
1. Instale Node.js.
2. Execute npm install.
3. Execute npm run dev.

## Publicar na Vercel
Build command: npm run build
Output directory: dist

## Estado atual
Esta é uma primeira interface demonstrativa. Os produtos e preços incluídos são dados iniciais e precisam ser confirmados pelo estabelecimento. O envio pelo WhatsApp é uma demonstração e usa temporariamente o número definido no código.

Ainda não há banco de dados, autenticação real, painel administrativo conectado, controle de estoque ou integração de pagamentos. Esses recursos precisam ser implementados e testados antes do uso comercial.

## Próximas etapas
1. Confirmar logo, telefone oficial, catálogo e preços.
2. Criar banco de dados e autenticação com permissões.
3. Implementar painel do proprietário, funcionários e administrador técnico.
4. Implementar pedidos persistentes, histórico, disponibilidade e relatórios.
5. Testar segurança, cálculos, permissões e fluxo de pedidos.
